## 1. Enemy State Pattern

- **IState**: `Enter()`, `Update()`, `Exit()`
- **StateMachine**: 상태 전환 및 `Update()` 호출
- **EnemyStateManager**: 몬스터 상태 머신

| 상태 | 클래스 | 설명 |
|------|--------|------|
| Patrol | EnemyPatrolState | 랜덤 이동/정지 |
| Chase | EnemyChaseState | 플레이어 추적 |
| Attack | EnemyAttackState | 공격 범위 내 연속 공격 |
| Dead | EnemyDeadState | 사망 애니메이션 |

```
Patrol ──(플레이어 범위)──> Chase
Chase ──(공격 범위)──> Attack
Chase ──(범위 밖)──> Patrol
Attack ──(범위 밖)──> Chase
* ──(HP 0)──> Dead
```

## 2. Enemy AI

**EnemyData (SO)**: MaxHp, Damage, ChaseRange, AttackRange, MoveSpeed, PatrolSpeed, PatrolRadius, PatrolDecisionMin/Max

**EnemyStateManager**: EnemyData, Player, Animator, SpriteRenderer, Dead Anim Duration, Ground Layer, Edge Check

- `IsGroundAhead(moveDirection)`: 낭떨어지 방지
- 기즈모: 노랑(추적), 빨강(공격), 초록(패트롤), 시안(낭떨어지)

## 3. 전투 시스템

### IDamageable

```csharp
void TakeDamage(float damage);
```

### 플레이어 → 적

- `Physics2D.OverlapBoxAll` 박스 판정
- `IsInAttackHitWindow()` (normalizedTime 0.3~0.55) 구간에만 데미지
- 인스펙터: Attack Range, Attack Height, Attack Offset X, Hit Window Start/End

### 적 → 플레이어

- `EnemyAttackState`: 공격 애니메이션(`IsInAttackAnim`) 중 `Player.GetComponentInChildren<IDamageable>().TakeDamage(Damage)`
- `_hasDealtDamage`로 공격당 1회만 적용

### 피격 처리

| 대상 | HP > 0 | HP ≤ 0 |
|------|--------|--------|
| 적 | DoHit 트리거 | Dead 애니 → 코루틴으로 `_deadAnimDuration` 후 Destroy |
| 플레이어 | - | `_hpUI.SetHp(CurrentHp)`로 UI 갱신 |

## 4. 플레이어 HP UI

**PlayerHpUI**: HP_Slot 자식(하트) 리스트 관리. `SetHp(currentHp)` 호출 시 남은 개수만큼 활성화.

- 기존 자식 사용 or HpIconPrefab으로 생성
- **연결**: PlayerController(Max Hp, Hp UI) ← PlayerHpUI(Hp Slot, Hp Icon Prefab)

---

## 5. 코루틴

**PlayDeadAndDestroy** (EnemyStateManager): Dead 상태 전환 → `WaitForSeconds(_deadAnimDuration)` → Destroy

- 즉시 Destroy 시 애니메이션 미재생이므로 코루틴 사용

## 6. 애니메이션 (MeleeEnemy1)

| 파라미터 | 용도 |
|----------|------|
| Speed | 0=Idle, 0.5=Walk, 1=Run |
| DoAttack, DoHit, IsDead | 공격, 피격, 사망 |

상태: Idle, Walk, Run, Attack, Hit, Dead. Hit/Attack → Idle (exit time). Hit 빠르면 Animator에서 Speed 낮추기.

## 8. 인스펙터 가이드

| 상황 | 조치 |
|------|------|
| 플레이어 공격 안 맞음 | Attack Range/Height↑, Attack Offset X 0 또는 음수 |
| Hit 모션 빠름 | Animator > Hit > Speed↓ |
| 적 이동 속도 | EnemyData MoveSpeed, PatrolSpeed |
| 패트롤 좁음 | EnemyData PatrolRadius↑ |
| 몬스터가 플레이어 때려도 HP 안 줄어듦 | EnemyStateManager Player 참조, 적 Animator Attack 상태명 확인 |
